# Sample worksheets (27 Nov 2026)

One sheet per homework type, as the printer gets it: the same `print.blade.php` → Dompdf PDF on Letter paper, rendered at 192 dpi (2×). Each sheet is at the level the hub would pick for that kid on 27 Nov 2026 (copied from the live progress levels).

They were made on a local test copy, not the live database:
- the number is a sample;
- "Nom" is left blank;
- the QR code points to example.invalid, with placeholder kid ids.

The AI writes the texts for division, grammar, reading and writing; the names in those texts are invented.

File names: `<type>-<grade>-L<level>.png`. L0 means the type has no levels yet.
